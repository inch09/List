                                                      Проект "СПИСОК"
В рамках данного проекта реализована структура данных, называемая списком. В отличие от массива в списке соседние элементы могут
не следовать друг за другом в памяти. В список можно добавлять элемент на любую позицию и удалять из него с любой позиции. Теперь поговорим подробнее про реализацию

__Как реализована наша структура данных?__
1) У нас имеется структура __List__, в которой имеется три массива(__data__, __next__, __prev__)(чуть позже станет понятно зачем), индексы первого и последнего элементов списка(__list__, __head__),индекс первого свободного элемента(__indOfFirstEmptyCell__), полный размер списка с учетом свободных элементов(__fullSizeOfList__), размер списка, учитывая только заполенные ячейки(__sizeOfList__)
2) Теперь поговорим о наших трех массивах. Массив __data__ хранит непосредственно наши данные. Массив __next__ хранит индексы следующих элементов(то есть __list.next[3]__ говорит нам о том, какой элемент в списке следует за элементом с индексом 3 в нашем массиве). Массив __next__ по аналогии хранит индексы предыдущих элементов
3) В массиве у нас есть свободные элементы. И чтобы не искать циклом каждый раз свободный элемент, мы в массивах __next__ и __prev__ храним последовательность свободных элементов. Но чтобы мы могли различать их, свободные элементы хранят индексы следующих и предыдущих со знаком минус   
__В целом, это главная информация о нашей структуре данных Список. Теперь перейдем к конкретике и поговорим о функциях__

__Основные функции:__
1)Функции __listInit__ и __listDestroy__ для создания и удаления списка соответственно
2)Функции __listPush__ и __listPop__  для добавления и удаления элемента по указанной позиции
3)Функция __listVerify__ для проверки того, что наш список правильный и не содержит ошибок
4)Функции __findElemByPosition__ и __findEmptyCell__ для поиска элемента по позиции и поиска свободного элемента
